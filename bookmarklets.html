⚔ WConseiller — Import en 2 clics

Plus besoin de la console F12. On installe deux marque-pages une fois, puis l’import se fait d’un clic.

Comment ça marche

  1. Glisse le bouton de ton site (ci-dessous) dans ta barre de favoris — une seule fois.
  2. Sur ta page de build, les caractéristiques affichées, clique le favori → un bandeau « Build copié » apparaît.
  3. Dans WConseiller, onglet Build, colle avec Ctrl+V → import automatique.

Wakfuli

📋 Copier mon build (Wakfuli)
⬆ glisse ce bouton dans ta barre de favoris
À utiliser sur la page ITEMS d’un build : wakfuli.com/builder/<id>/items, avec le panneau de caractéristiques affiché.

Zenith

📋 Copier mon build (Zenith)
⬆ glisse ce bouton dans ta barre de favoris
À utiliser sur zenithwakfu.com/builder/<id>, avec la section caractéristiques du personnage visible.
⚠ Les bookmarklets ne fonctionnent que sur navigateur de bureau (pas mobile). Si un clic dans cette page ne fait rien, c’est normal : il faut d’abord glisser le bouton dans les favoris, puis cliquer le favori sur la page du build. Si la copie est bloquée, une boîte s’ouvre avec le JSON pré-sélectionné (Ctrl+C).
